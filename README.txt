CRISTOPH'S PORTFOLIO WEBSITE

FILES
- index.html: page content and sections
- style.css: layout, colors, sizing, responsive design
- script.js: vertical description carousel and smooth navigation
- assets/: images taken/cropped from your uploaded screenshot

HOW TO RUN
1. Extract the ZIP file.
2. Keep index.html, style.css, script.js, and the assets folder together.
3. Open index.html in Chrome, Edge, Firefox, or another browser.
4. For editing, open the whole folder in Visual Studio Code.

HOW TO CHANGE IMAGES
Replace the image inside assets while keeping the same filename:
logo.png, profile.png, java.png, python.png, problem-solving.png, computer-skills.png.
If you use a different filename, update the matching src in index.html.

HOW TO EDIT TEXT
Edit the introduction and skill titles/descriptions in index.html.
The three sets of carousel descriptions are in script.js.

CONTACT LINKS
The phone link uses tel:, Facebook opens in a new tab, and Gmail uses mailto:.
